# AI 前沿日报 v9｜离线优先跨设备同步准备版

v9 是正式上线前最后一个“纯本地开发阶段”版本。

## 新增

### 跨设备同步层
项目新增：

- `sync-core.js`
- `sync.js`
- `config/sync.json`
- `db/supabase_schema.sql`

支持同步：

- 收藏
- 已读
- 观察词
- 个性化学习结果
- 阅读偏好
- 5 / 10 分钟模式
- 为你排序

### 离线优先

云同步不是前提。

即使：

- 没配置 Supabase
- 断网
- 登录过期
- 云端故障

日报仍然完全可以本地阅读和使用。

### 冲突合并

不是简单“最后一台设备覆盖全部”。

收藏、已读、观察词采用逐项时间戳合并：

- 电脑收藏 A
- 手机收藏 B
- 最后同步后 A 和 B 都保留

删除动作同样带时间戳，可以跨设备传播。

### 同步页面

导航新增：

`同步`

未配置云端时，会明确显示“云同步尚未启用”。

配置后会出现：

- 注册
- 登录
- 立即同步
- 退出同步账号

### 自动同步

登录后：

本地收藏、已读、观察词、学习偏好发生变化，会延迟约 1 秒自动同步，减少频繁请求。

### 自动测试

新增：

`tests/test_sync.js`

测试：

- 不同设备新增内容合并
- 同一条记录最新时间戳获胜
- 删除动作能同步
- 阅读模式冲突正确合并
